## 1. 保存するデータ

| データ | 個人データ | 保存先 | 保持期間 | 削除方法 |
| --- | --- | --- | --- | --- |
| 組織（社名・メールドメイン・設定） | — | PostgreSQL | 契約期間中 | 解約時に削除 |
| メンバー（表示名・メールアドレス・ロール） | **該当** | PostgreSQL | 在籍中 | 退職処理で即時無効化、30日後に匿名化 |
| フォーカスカード（今週やること 3〜5件） | 該当（本人が書いた業務内容） | PostgreSQL | 無期限（本人がいつでも削除可） | 本人が削除 / 退職時 |
| タスク（プロジェクト単位） | 該当（担当者が紐づく） | PostgreSQL | 無期限 | 組織設定で一括削除可 |
| チャットメッセージ | **該当** | PostgreSQL | **組織設定で 90日 / 1年 / 無期限** | 期間経過で自動削除 |
| 会議室の予約（未来の予定） | 該当（予約者名） | PostgreSQL | 終了から **30日** | 自動削除 |
| ホワイトボードの内容 | 該当しうる | PostgreSQL | 無期限（手動で消去可） | 本人・参加者が消去 |
| 監査ログ | 該当（操作者） | PostgreSQL | **既定1年・組織設定で変更可** | 期間経過で自動削除 |
| フロアのマップ定義 | — | PostgreSQL | 契約期間中 | — |

### 揮発データ（消える前提のもの）

| データ | 保存先 | 保持期間 |
| --- | --- | --- |
| いまどこにいるか（座標・ステータス） | **Redis（永続化を無効化）** | **30秒**（heartbeat が止まれば自然消滅） |
| 進行中の会話（参加者・room） | Redis | 会話終了で削除 |
| ノック要求 | Redis | 60秒 |
| 着席の状態 | Redis | プレゼンスに追従 |

> **Redis の永続化（AOF / RDB）を無効にしているのは設計判断である。**
> 高速化のためではなく、**「明示的に消さなくてもいずれ必ず消える」**状態を作るため。
> プロセスが再起動すれば、その時点のプレゼンスは跡形もなく消える。

## 2. 保存しないデータ（製品の約束）

以下は **意図的にスキーマが存在しない**。
「設定で無効にできる」ではなく「**そもそも保存していない**」。

| 保存しないもの | 保存すれば何ができてしまうか |
| --- | --- |
| 位置の履歴 | 誰がいつどこにいたかの完全な追跡 |
| 会話の履歴（誰と誰が何分話したか） | 人間関係グラフの復元 |
| セッションログ・オンライン時間 | 個人別の稼働時間・稼働率 |
| 最終ログイン日時（`lastSeenAt`） | 実質的な在席ログ |
| タスクの完了時刻（`completedAt`） | 個人別の消化数・ベロシティ |
| 他人に見える既読（`readAt`） | 「見たのに返さない」の可視化 |
| 発話時間・発言回数 | 会議での発言量の評価利用 |
| 通話の録音・録画・文字起こし | 会話内容の保存（情報漏洩リスクそのもの） |
| 画面のスクリーンショット | 同上 |
| キー入力・アクティブアプリ | ステータスの自動推定 |

**管理者ロールであっても、これらを取得する API が存在しない。**
権限で禁止しているのではなく、データもエンドポイントも無い。

> この一覧は製品内の **設定 →「記録しないもの」** ページに常設表示し、
> 利用者がいつでも確認できるようにする（[03 M-15](../design/03-features.md)）。
> スキーマ側の担保は [05 §5](../design/05-data-model.md)。

## 3. 集計値の扱い

管理者に見せる数字は、**個人を特定しない形でのみ**算出する。

| 出力 | 算出方法 | 個人特定性 |
| --- | --- | --- |
| 「詰まり」（プロジェクト単位） | 3日以上動いていない項目数を projectId で `GROUP BY` | **なし**（`userId` を SELECT しない） |
| フォーカスカードの週次更新率 | 当週レコード数 ÷ 有効メンバー数 | なし（組織全体の比率のみ） |
| 同時接続数の推移 | プレゼンス件数を**数値のみ**時系列で保存 | なし（誰が、を持たない） |
| 会話の長さの中央値 | 終了時に**長さだけ**をヒストグラムに加算 | なし（参加者を持たない） |

最下段が要点である。会話の長さを知りたければ、
**「誰が」を捨てて長さだけを集計すればよい。** レコードとして残す必要はない。

## 4. 暗号化

| 対象 | 方式 |
| --- | --- |
| 転送時（HTTP / WebSocket） | TLS 1.3 |
| 転送時（音声・映像） | DTLS-SRTP + **E2EE（AES-GCM 256）** |
| 保存時（PostgreSQL） | ディスク暗号化（クラウドの標準機能 / セルフホストは顧客の設定） |
| 保存時（Redis） | **永続化していないためディスクに書かれない** |
| バックアップ | 暗号化した上で保管。復号鍵は別管理 |

## 5. データ主体の権利への対応

| 求め | 対応 |
| --- | --- |
| 開示 | 本人分のエクスポート（フォーカスカード・タスク・チャット）を Markdown / CSV で出力 |
| 訂正 | 本人が UI から編集できる |
| 削除 | フォーカスカードは本人が随時削除可。アカウント削除は管理者経由で30日後に匿名化 |
| 利用停止 | 管理者が無効化。**トークンが短命（5分）なので最大5分で全アクセスが失効する** |
| 持ち出し | 上記エクスポート |

退職時の挙動:

- `deactivatedAt` を立てて**即時にログインを遮断**
- 30日後に個人データを匿名化。過去の発言は「退職したメンバー」表示になる
- **SCIM に対応すれば IdP 側の退職処理と連動する**（[03 S-09](../design/03-features.md)、Phase 4 以降）

## 6. サブプロセッサ

| 形態 | サブプロセッサ |
| --- | --- |
| SaaS | クラウド事業者（計算・保管・帯域）。**リージョンは契約時に明示する** |
| **セルフホスト** | **なし** |

- 解析 SaaS、エラー収集 SaaS、CDN、外部フォント配信を**使わない**（[01 §4](./01-endpoints.md)）
- AI による文字起こし・要約サービスを**使わない**（そもそも録音しない）

## 7. 提出時のチェックリスト

- [ ] 保持期間の既定値が、顧客の社内規程と矛盾しないか確認した
- [ ] チャットの保持期間（90日 / 1年 / 無期限）を顧客と決めた
- [ ] 監査ログの保持期間（既定1年）が監査要件を満たすか確認した
