情シス向け: この診断が確認していること

ブラウザ … WebRTC と WebSocket に対応しているか。
HTTPS … 安全なコンテキストで配信されているか（WebRTC の前提条件）。
WebSocket … 443/TLS の長時間接続が Proxy や SSL インスペクションで切られないか。
UDP … STUN で反射アドレス（srflx）が取れるか。取れなければ UDP は塞がれている。
TURN/TCP 443 … UDP が塞がれていても中継（relay）候補が取れるか。ここが通れば通話は成立する。
往復遅延 … WebSocket のエコー往復時間。
帯域 … 既知サイズのファイルの取得時間からの概算。

いずれの項目も、送信するのは接続の試行だけです。端末の情報・入力・音声は一切扱いません。 マイクやカメラの許可も求めません。
