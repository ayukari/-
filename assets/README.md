# assets — アバターを作るスクリプト

**[avatar.blend.py](./avatar.blend.py) が Blender の中で走り、
`client/assets/avatar-{0,1,2}.glb` を書き出す。**

```bash
blender --background --python assets/avatar.blend.py -- --out client/assets
```

出力（2026-09-13 実測）:

```
avatar-0.glb  頂点 714  三角形 1244  121.5 KB
avatar-1.glb  頂点 756  三角形 1324  124.1 KB
avatar-2.glb  頂点 760  三角形 1328  125.6 KB
合計 371.2 KB  (10 §2 の予算 4.8MB のうち)
```

**生成物はリポジトリに入れてある。** アプリを動かすのに Blender は要らない。
形を変えたいときだけ、Blender を入れてこのスクリプトを走らせ直す。

## なぜ手で作らずスクリプトにしたのか

| 理由 | |
| --- | --- |
| **寸法規約を人手で守らせない** | 1タイル = 1ユニット ≒ 1.0m、+Z が正面（[10 §5](../docs/design/10-assets.md)）。スクリプトが定数として持っている |
| **予算を見ながら形を決められる** | 走らせるたびに三角形数が出る。1,400（[10 §4](../docs/design/10-assets.md)）を超えたら気づく |
| **ライセンスの出所が問題にならない** | 商用可・改変可・**再配布可**（[10 §6](../docs/design/10-assets.md)）を自前で満たす。情シス審査で素材の出所を説明する必要が無い |
| **3体型の差分を書き間違えない** | 太さの係数1つを変えるだけで、骨も動きも共通のまま別体型になる |

## 作りの決まり

- **テクスチャを1枚も使わない。** 色は全部 頂点カラー に入っている
- **頂点カラーのアルファに「部位ID」を入れる。**
  クライアントはそれを見て人ごとに肌・髪・服を塗り替える（`client/src/avatar.js`）
- **マテリアルは1つ。** だから **1人 = 1ドローコール**
- 球は滑らかに、円錐と箱はフラットのまま。低ポリらしさを残すため
- 顔の部品（目・まゆ・ほお・口）は `face_y()` で**頭の表面から計算して貼る**。
  手で深さを決めていたときは輪郭から浮いていた

## 落とし穴

**glTF エクスポータは、マテリアルがアルファを使っていないと COLOR_0 を VEC3 に落とす。**

部位IDはそのアルファに入っているので、落ちると**全員が同じ色で立つ**。
`material()` が `Color Attribute → Alpha → BSDF Alpha` を繋いでいるのはそのためで、
消すと壊れる。`server/test/assets.test.js` が VEC4 であることを検査している。

## 骨と動き

18本（[10 §4](../docs/design/10-assets.md) の上限）。指も表情も持たない。

| クリップ | 長さ | 中身 |
| --- | --- | --- |
| `idle` | 61f (2.0s) | 呼吸で胸と肩がわずかに動く。止まって見えないことが大事 |
| `walk` | 25f (0.8s) | 歩幅 22°。移動速度 4.2タイル/秒 に対して速すぎない |
| `sit` | 61f (2.0s) | 椅子の座面 0.42m に合わせて腰を 0.39m 落とす |

すねの曲げは `walk` と `sit` で**符号が逆**になる（`sit` は腿から見て下へ曲げる）。
最初これを間違えて、足が宙に上がったまま座っていた。

## 確認のしかた

`client/avatar-preview.html` を開く（dev サーバ起動中に `/avatar-preview.html`）。
体型・クリップ・配色を切り替えられて、三角形数とドローコールがその場に出る。
