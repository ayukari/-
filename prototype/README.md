# 操作プロトタイプ

`index.html` の1ファイルだけで動きます。ビルド不要。ブラウザで開いてください。

**公開版**: https://claude.ai/code/artifact/ba1caabc-6311-47c7-9135-83dd27756a46

```bash
# ローカルで開く場合
open prototype/index.html      # macOS
```

## 何を試せるか

| 流れ | 内容 |
| --- | --- |
| 1. アバターを作る | 名前・体型・色。3Dプレビューが即座に変わる |
| 2. チームに入る | チームごとの部屋。在室人数と「詰まり」件数が入る前に見える |
| 3. 部屋に入る | 3D空間を歩き、同僚に近づき、席に座って通話を始める |

### 操作

| | PC | スマホ・タブレット |
| --- | --- | --- |
| 移動 | `WASD` / 矢印キー、クリックした場所へ歩く | **タップした場所へ歩く。指を置いたまま動かすと追いかける** |
| 着席（通話開始） | 席の上で `E` | 席の上で右下の**丸ボタン「座る」** |
| 離席 | 下部バーの「席を立つ」 | 丸ボタン「立つ」 |
| 今週のカード / メンバー | 右パネル（常時表示） | 下部バーの**「今週」で下から出るシート** |
| 表示切替 | 左上の 3D / 2D / リスト | 同じ（左上、コンパクト表示） |

スマホは縦画面を想定し、カメラの見下ろし角を強めて画面に部屋が収まるようにしてある。
描画解像度もタッチ端末では 1.25x に抑えている（[02 §6.4](../docs/design/02-problem-solving.md) の解像度スケーリング）。

## 設計のどこを実演しているか

| 実演 | 対応する設計 |
| --- | --- |
| **左上の 3D / 2D / リスト 切り替え** | [02 §6.1](../docs/design/02-problem-solving.md) 論理レイヤーと表現レイヤーの分離。どの表示でも同じ場所に立っている |
| **近づいてもマイクが繋がらない** | [00 原則1](../docs/design/00-overview.md)。リングと相手のフォーカスカードが出るだけ。着席して初めて「マイク接続中」になる |
| **「集中中」の人には近づいても何も起きない** | [00 原則2](../docs/design/00-overview.md) |
| **アバターの上に出る吹き出し** | [03 M-11](../docs/design/03-features.md) フォーカスカードの可視化。「今なにやってるんですか?」を聞かずに済む |
| **右パネルの「今週のわたし」** | [02 壁1](../docs/design/02-problem-solving.md) フォーカスカードが中核 |
| **左上のドローコール / 三角形数** | [04 §4.6](../docs/design/04-architecture.md) の描画予算（ドローコール100未満 / 三角形150k未満）を実測で見せる |
| **影なし・動的ライトなし・固定カメラ** | [02 §6.3・§6.7](../docs/design/02-problem-solving.md) |
| **リストモードでも成立する** | [02 §6.5](../docs/design/02-problem-solving.md) 空間を捨ててもプロダクトが残る |
| **スマホで一通り操作できる** | [03 C-05](../docs/design/03-features.md) のモバイル閲覧。ただし空間まで動くのは想定以上 |

## これは何ではないか

**見た目と操作感を確かめるための試作です。** 以下は入っていません。

- サーバ・データベース・認証（すべてブラウザ内のダミーデータ）
- 実際の WebRTC / 音声（「マイク接続中」は状態表示のみ。`getUserMedia` を呼んでいません）
- 他の人との同期（同僚は台本どおりに動くNPC）
- 3Dアセット（すべてコード内のプリミティブ）

実測が必要なもの（低スペック実機での fps、E2EE の負荷、TURN の疎通）は
[06. ロードマップ](../docs/design/06-roadmap.md) の Phase 0 で扱います。
