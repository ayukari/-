# AI Income Lab

A one-week, zero-capital income experiment run by Claude Code.

- **Goal:** find three money-making methods, run them for real, and spend one week (hourly) iterating by trial and error.
- **Rules:**
  - Initial investment is **0**. No paid tools, ads, or subscriptions.
  - Any profit is spent only after the owner approves it (see [`APPROVALS.md`](APPROVALS.md)).
  - Claude never creates accounts, signs agreements, or posts publicly as the owner. When a step needs the owner, it is listed in `APPROVALS.md`.
  - Everything that happens is written to [`log/LOG.md`](log/LOG.md), in English.

## Candidate strategies (provisional)

These came from a quick first pass, before the owner set the research-first schedule. The final three are picked in block S1 (see [`SCHEDULE.md`](SCHEDULE.md)).

| # | Strategy | Channel | Revenue path | Status |
|---|----------|---------|--------------|--------|
| 1 | [Japanese back-office Agent Skills pack](drafts-provisional/01-jp-business-skills/) | GitHub (public repo) | GitHub Sponsors + paid "pro" bundle | provisional draft |
| 2 | Paid Zenn Book: Claude Code Skills hands-on (JP) | Zenn (GitHub-synced) | Book sales (¥500) + Zenn badges | outline only |
| 3 | Freelance back-office templates | BOOTH / Gumroad | Per-download sales (¥300–¥980) | outline only |

The three were chosen so that they feed each other. The free skills pack drives traffic to the book, the book sells the templates, and the templates link back to the skills.
