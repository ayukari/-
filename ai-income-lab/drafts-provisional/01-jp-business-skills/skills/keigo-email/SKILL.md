# keigo-email: ビジネスメールの作成と敬語添削

## まず決めること
作成前に次の3点を確認する。推測できるものは推測し、推測した内容を一言添える。

| 項目 | 選択肢 |
|---|---|
| 相手との関係 | 社外・初対面 / 社外・取引中 / 社内・目上 / 社内・同僚 |
| 目的 | 依頼 / 催促 / お詫び / お断り / お礼 / 日程調整 / 報告 |
| トーン | 丁寧（標準） / かなり丁寧（お詫び・重大な依頼） / やや簡潔（社内） |

## 構成
1. **件名**: 用件と期日がひと目でわかるように書く（例: 「【ご確認依頼】10/10締切 見積書の件」）
2. **宛名**: 社外なら「株式会社〇〇 〇〇部 〇〇様」
3. **挨拶と名乗り**: 「いつもお世話になっております。〇〇の△△です。」（初対面なら「突然のご連絡失礼いたします。」）
4. **要件**: 結論を先に書き、詳細は箇条書きにする
5. **相手にしてほしいこと**: 期日と方法を具体的に書く
6. **結び**: 目的に合った結びの言葉にする

## 添削でよく直す誤り
| 誤り | 修正 |
|---|---|
| 了解しました（目上へ） | 承知しました／かしこまりました |
| ご苦労様です（目上へ） | お疲れ様です |
| 拝見されましたか | ご覧になりましたか |
| おっしゃられる（二重敬語） | おっしゃる |
| 〜させていただきます（多用） | 〜いたします |
| 参考になりました（目上へ） | 勉強になりました |
| 〜になります（「です」の意味） | 〜です／〜でございます |

## 催促メールのコツ
- 責める表現を避け、「行き違いでしたら失礼いたします」を入れる
- 元の依頼日・期日・対象を具体的に書く
- 新しい期日を明示する

## 出力形式
件名と本文を出力し、続けて「変更点（添削時）」を箇条書きで示す。
