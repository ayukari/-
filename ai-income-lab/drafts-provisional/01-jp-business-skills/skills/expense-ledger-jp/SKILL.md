# expense-ledger-jp: 経費帳づくり

## 入力
- カード明細CSV、銀行明細、レシートの書き起こし、箇条書きのメモなど、形式は問わない

## 出力CSV（列は固定）
```csv
日付,取引先,内容,勘定科目,金額(税込),税率,インボイス登録番号,家事按分率,経費算入額,メモ
2026-10-01,ABCクラウド,サーバー代,通信費,1100,10%,T1234567890123,100%,1100,
2026-10-02,〇〇電力,電気代,水道光熱費,8800,10%,,30%,2640,自宅兼事務所
```

## 勘定科目の目安
| 内容 | 勘定科目 |
|---|---|
| ネット回線・サーバー・スマホ | 通信費 |
| ソフト・SaaS月額 | 通信費 または 支払手数料（どちらかに統一する） |
| 電車・タクシー・出張宿泊 | 旅費交通費 |
| 書籍・オンライン講座 | 新聞図書費 / 研修費 |
| 10万円未満のPC・周辺機器 | 消耗品費 |
| 打ち合わせの飲食 | 会議費 / 接待交際費 |
| 振込手数料・決済手数料 | 支払手数料 |
| 電気・ガス・水道 | 水道光熱費（家事按分） |
| 家賃 | 地代家賃（家事按分） |

## 手順
1. 入力を1行1取引に分解する。
2. 勘定科目を振り分ける。迷うものはメモ列に「要確認」と書き、まとめて質問する。
3. 家事按分は、ユーザーが割合を決めていなければ空欄にして質問する。勝手に決めない。
4. `経費算入額 = 金額 × 家事按分率` を計算する。
5. 最後に勘定科目ごとの合計表を示す。

## 注意
- 10万円以上の備品は減価償却や一括償却資産の対象になりうるので、「要確認」にする。
- 税務の最終判断は税理士・税務署に確認するよう伝える。
