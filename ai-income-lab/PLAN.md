## 1. Research (prior art)

Searched the web and GitHub on 2026-10-04.

**Web findings**
- Digital products (templates, guides, prompt packs, agent templates) are the most common zero-capital AI income path. There is no inventory and almost no marginal cost. Agent and workflow templates on Gumroad are reported at $47–$497 each. ([emergent.sh](https://emergent.sh/learn/how-to-make-money-with-ai), [AK Academy](https://ak-academy.ai/ai-businesses-no-capital/), [bestaiagentcommunity](https://bestaiagentcommunity.com/blog/how-to-make-money-building-ai-agents/))
- Claude Code skills are now a monetizable category. Single skills sell for $5–$25. The best niche skills are reported at $500–$3,000 a month, and the usual model is "free public repo + paid private bundle". ([agent37](https://www.agent37.com/blog/monetize-claude-code-skills), [agensi](https://www.agensi.io/learn/how-to-monetize-skill-md-skills-developer-guide-2026))
- In Japan, Zenn Books sell from ¥200 to ¥5,000, can mix free and paid chapters, and sync from a GitHub repo. Unknown authors report first sales of 5 copies at ¥500 and a ¥1,500 book that sold. note paid articles performed worse in at least one public report. ([zenn.dev](https://zenn.dev/yushiyamamoto/articles/zenn-revenue-os-public-experiment), [Qiita](https://qiita.com/sakutto-panda/items/62a973b2ddce6da4437f), [note](https://note.com/smallworkslab/n/n93ee005d6590))

**GitHub findings (mod / skills search)**
- General Claude Code skill repos are very crowded. The top repos have 50k–270k stars.
- Japanese-language skill repos are a thin niche. `coji/natural-japanese` (business Japanese writing) reached about 1.9k stars in 3 months, and most other JP skill repos are under 150 stars. There is **no visible JP back-office pack** (invoice-system invoices, keigo email, expense ledger), so this is the gap we target.

## 2. Why these three

The bar: zero capital, can be built mostly by Claude, has a real payment rail, and has long-term revenue potential. A first sale within the week is **not** required (owner, 2026-10-04).

| Option considered | Verdict |
|---|---|
| Affiliate spam bots (Reddit/X) | **Rejected.** Breaks platform rules and risks the owner's accounts. |
| Trading / crypto | **Rejected.** Needs capital and is not zero-risk. |
| Bug bounties | **Rejected for now.** Needs explicit program scope and a long ramp. |
| Freelance gigs | **Rejected for now.** Needs the owner's identity and live client handling. |
| **JP skills pack + Sponsors** | **Chosen.** It is an empty niche and Claude can build it end to end. |
| **Zenn paid book** | **Chosen.** It syncs from GitHub, so Claude can write it in place. |
| **BOOTH/Gumroad templates** | **Chosen.** Listing is free and they reuse the same domain knowledge. |

## 3. Success metrics (week 1)

Realistic targets for a brand-new, zero-follower account:

| Metric | Target by day 7 |
|---|---|
| Skills repo stars | ≥ 10 |
| Zenn book published, chapters | 1 book, ≥ 8 chapters |
| Templates listed | ≥ 2 listings |
| First revenue | Not required in week 1 (owner, 2026-10-04) |

The honest expectation is that revenue in week 1 is **likely ¥0–¥3,000**. The real output of the week is the assets and the learning about which channel converts.
